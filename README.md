# FB-CPU-RTL

A simple CPU design project implemented in Verilog HDL.

## Overview

This project focuses on the design and implementation of a basic CPU at the RTL level using Verilog.

## Technologies

- Verilog HDL
- RTL Design
- Digital Logic Design
- CPU Architecture

## Project Structure

```text
FB-CPU-RTL-
├── fb-CPU.v
└── README.md
```

## Purpose

The project was developed to practice RTL design, CPU architecture, and hardware description using Verilog.
